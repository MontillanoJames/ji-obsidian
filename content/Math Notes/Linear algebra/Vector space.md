 >[!Definition] Vector Space
>A *vector space* $V$ over a field $F$ is a nonempty set of elements, called *vectors*, with two operations called *vector addition* (or *addition*) and *vector multiplication* (or *multiplication*)  satisfying the following conditions for any $\alpha, \beta, \gamma \in V$ and for any $a, b \in F$:
>
>V1. $\alpha + \beta \in V;$  
>V2. $(\alpha + \beta) + \gamma = \alpha + (\beta + \gamma);$  
>V3. $\exists 0 \in V$ such that $\alpha + 0 = \alpha$, $\forall \alpha;$  
>V4. $\exists -\alpha \in V$ where $\alpha + (-\alpha) = 0;$  
>V5. $\alpha + \beta = \beta + \alpha;$  
>V6. $a\alpha \in V;$  
>V7. $a(b\alpha) = (ab)\alpha;$  
>V8. $a(\alpha + \beta) = a\alpha + a\beta;$  
>V9. $(a + b)\alpha = a\alpha + b\alpha;$  
>V10. for $1 \in F$, $1 \cdot \alpha = \alpha.$
